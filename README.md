# Talk-to-Data · Silia

Reto de Product Designer para Creai. Diseño e implementación de un **agente conversacional** sobre la Data View de Silia: un widget flotante que permite filtrar, resumir y visualizar los datos de la tabla en lenguaje natural, sin sacar al usuario de su flujo.

La tesis: **el chat es donde creas; la Data View es donde lo que creas cobra vida.** Los outputs del agente (filtros, vistas, gráficos, resúmenes) se vuelven objetos de primera clase que viven en las superficies que Silia ya tiene —vistas guardadas y dashboard—, reutilizando sus acciones en lugar de duplicarlas.

## Enlaces

- **Prototipo navegable:** https://talktodata-munguia.vercel.app/
- **Material complementario:** https://talktodata-munguia.vercel.app/material.html

## Qué incluye

- **Prototipo** (`index.html`) — Data View funcional (búsqueda, filtros encadenables, configurador de columnas, orden) + widget conversacional flotante con gestión de outputs.
- **Material complementario** (`material.html`) — mapa de interacciones, decisiones y trade-offs, y nota de escalabilidad.

## Stack

HTML, CSS y JavaScript en un solo archivo, sin build. El "agente" es un intérprete de intención determinista, pensado para que la experiencia de diseño no dependa de conectar un modelo real.
